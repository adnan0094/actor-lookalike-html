# ممثل شبيه - Actor Lookalike

تطبيق ويب بسيط وأنيق يساعدك على اكتشاف أي ممثل سوري تشبهه من خلال تحليل ملامح وجهك.

## المميزات

- 📸 **رفع الصور** - رفع صورة من جهازك أو التقط من الكاميرا مباشرة
- 🎬 **مقارنة ذكية** - مقارنة ملامحك مع 20+ ممثل سوري مشهور
- ⚡ **نتائج فورية** - احصل على النتيجة في ثوانٍ معدودة
- 🌐 **دعم اللغات** - واجهة عربية وإنجليزية
- 📱 **متوافق مع الهاتف** - تصميم متجاوب يعمل على جميع الأجهزة
- 💾 **سجل المقارنات** - احفظ جميع مقارناتك السابقة

## البنية التحتية

```
actor-lookalike-html/
├── index.html          # الصفحة الرئيسية
├── upload.html         # صفحة رفع الصور
├── results.html        # صفحة النتائج
├── history.html        # صفحة السجل
├── css/
│   └── style.css       # الأنماط الرئيسية
├── js/
│   ├── app.js          # التطبيق الرئيسي
│   ├── translations.js # الترجمات
│   ├── upload.js       # معالجة الرفع
│   ├── results.js      # معالجة النتائج
│   └── history.js      # معالجة السجل
└── README.md           # هذا الملف
```

## الاستخدام

1. **افتح الصفحة الرئيسية** - اضغط على "ابدأ الآن"
2. **اختر صورة** - رفع صورة أو التقط من الكاميرا
3. **احصل على النتيجة** - سيتم عرض الممثل الأكثر شبهاً
4. **شارك النتيجة** - شارك النتيجة مع أصدقائك
5. **اطلع على السجل** - عرض جميع مقارناتك السابقة

## التكنولوجيا المستخدمة

- **HTML5** - للهيكل الأساسي
- **CSS3** - للتصميم والأنماط المتقدمة
- **JavaScript** - للوظائف التفاعلية
- **LocalStorage** - لحفظ البيانات محلياً

## المتطلبات

- متصفح حديث يدعم:
  - HTML5 Canvas
  - MediaDevices API (للكاميرا)
  - LocalStorage
  - FileReader API

## التثبيت والتشغيل

### الطريقة 1: تشغيل محلي مباشر
```bash
# فقط افتح index.html في المتصفح
open index.html
```

### الطريقة 2: استخدام خادم محلي
```bash
# باستخدام Python 3
python3 -m http.server 8000

# ثم افتح في المتصفح
http://localhost:8000
```

### الطريقة 3: استخدام Node.js
```bash
# تثبيت http-server
npm install -g http-server

# تشغيل الخادم
http-server

# افتح في المتصفح
http://localhost:8080
```
